# Поликлиника – аналитика

Веб-приложение для анализа работы поликлиники: статистика приёмов, время ожидания, нагрузка врачей и контроль плановых показателей. Включает интерактивные графики, реестр приёмов, фильтрацию данных и экспорт CSV.

Разработано на HTML, CSS и JavaScript с использованием IndexedDB.
