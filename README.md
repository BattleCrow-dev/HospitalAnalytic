# Поликлиника — аналитика

Статическое веб-приложение на HTML, CSS и JavaScript. Хранилище — IndexedDB. Внешние библиотеки и сборка не требуются.

## Запуск

Откройте папку проекта в VS Code и запустите Live Server или выполните:

```sh
python -m http.server 8000
```

Адрес: http://localhost:8000.

## Публикация

Загрузите содержимое папки в корень репозитория GitHub. В Settings → Pages выберите Deploy from a branch → main → / (root).

## Структура

- `index.html` — экранные формы.
- `style.css` — оформление и адаптация.
- `js/storage.js` — создание IndexedDB, проверка связей и чтение записей.
- `js/analytics.js` — подготовка данных, фильтрация и вычисления.
- `js/ui.js` — таблицы, графики, пагинация и экспорт.
- `js/app.js` — состояние интерфейса и обработчики.
- `data/clinic.json` — исходные записи пяти связанных таблиц.

При первом запуске JSON загружается в IndexedDB, при последующих — записи читаются из базы. Обновление исходного JSON само по себе не перезаписывает существующее хранилище. Для повторной инициализации можно удалить `clinic_analytics_v5_expanded` в DevTools → Application → IndexedDB.
